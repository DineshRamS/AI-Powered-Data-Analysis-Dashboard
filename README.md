# AI-Powered Data Analysis Dashboard

An interactive Streamlit dashboard for analyzing e-commerce sales data.

## Project Overview

This project provides an easy-to-use dashboard where users can upload CSV or Excel datasets and perform data analysis through interactive visualizations, KPIs, filtering, anomaly detection, AI-powered insights, and business recommendations.

## Features

- CSV and Excel dataset upload
- Data validation and preprocessing
- Dataset overview and statistical summary
- KPI cards
- Interactive Bar Chart
- Line Chart
- Pie Chart
- Histogram
- Scatter Plot
- Correlation Heatmap
- Search and filtering
- Anomaly and outlier detection
- AI-powered data insights
- Business recommendations
- Summary report generation

## Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- OpenPyXL

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the application:

streamlit run app.py
